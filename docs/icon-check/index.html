Issue #20 · Epic E9 · die 24 normalisierten Symbole aus assets/img/icons/
Die Symbole werden nicht als fertiges Bild gezeichnet, sondern als Maske eingefärbt — die Silhouette gibt die Form, die Farbe kommt aus der Schule (GAME-DESIGN 9.3). Deshalb steht hier jedes Symbol dreimal: auf dunklem Grund wie im Spiel, auf hellem Grund (dort fiele jeder dunkle Rand sofort auf, AC3) und unverändert als Rohdatei.

Auf dunklem Grund — wie in der Zauberleiste

Slot 92 px, Symbol 72 px, eingefärbt in den fünf Schulfarben der Reihe nach.

Auf hellem Grund — AC3: keine dunklen Ränder

Dunkel eingefärbt auf hellem Papier. Ein Rest aus einem Freisteller zeigte sich hier als heller oder grauer Saum um die Form.

Rohdatei, unverändert

Weiße Silhouette, wie sie von game-icons.net kommt und im Repository liegt.
