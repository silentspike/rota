# Welche Groesse ist wogegen geprueft? — Rohdaten zu docs/GROESSEN-ABDECKUNG.md
#
# Eine Zeile je Feld-Zauber-Paar:
#
#   FELD  ZAUBER  ALT -> NEU  [RICHTUNG]  URTEIL  || GEGENRICHTUNG: ZUSTAND
#
# RICHTUNG ist aus ALT und NEU gerechnet: SENKEN, ANHEBEN oder TAUSCH (bei
# Werten, die keine Groessen sind, etwa control.effect).
#
# GEGENRICHTUNG hat genau drei Zustaende:
#
#   gemessen/gedeckt    die andere Richtung wurde gefahren und faerbte
#   gemessen/offen      sie wurde gefahren und faerbte NICHT
#   nicht gemessen      sie wurde nie gefahren
#   nicht anwendbar     der Wert ist keine Groesse (TAUSCH-Zeilen)
#
# WARUM DIE SPALTE UEBERALL 'nicht gemessen' ZEIGT (Issue #1094): Sie tut es
# nicht ueberall — drei Paare sind nachgemessen. Der Rest ist der ehrliche
# Ausgangszustand. Die Vollmessung hat je Paar EINE Richtung gefahren, und bei
# den Zahlen-Groessen war das ausnahmslos die Senkung: 'tools/groessen-hebel.py'
# rechnet 'vorher // 2' beziehungsweise '1 if vorher == 0'. Eine Spalte, die
# nach dem Umbau ueberall 'gedeckt' zeigt, waere der Beweis, dass niemand
# gemessen hat.
#
# ZEILEN MIT '#' SIND KOMMENTAR. 'grep -cvE "^#|^$"' zaehlt weiter die Paare.
